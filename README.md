# Full-Stack-Expense-Tracker

This is full stack Expenses Tracker built using tech stack - React, Node, Express and PostgreSQL.

write .env file to run this project

in backend - 
DATABASE_URI = YOUR DATABASE URI
PORT=5001
JWT_SECRET= YOUR JWT SECRET KEY - mysecret12345

in frontend - 
VITE_API_URL=http://localhost:5001/api-v1
